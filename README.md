# Mentivor AI

Free, open-source AI image-generation system for consistent cinematic
illustrated scenes for the Mentivor YouTube channel (money psychology,
wealth, behavior, motivation).

Core goal: character identity + universe style + scene content + 
cinematography as independently controllable, reusable components.

## Status
Phase 1 — repository and character schema setup.

## Development environment
- Local: Windows 11, Python 3.11, no CUDA GPU — used for code, config,
  dataset curation, and prompt/scene logic only.
- Training & heavy inference: free cloud GPU (Kaggle / Google Colab).

See `training/notebooks/` (added in later phases) for cloud training work.
